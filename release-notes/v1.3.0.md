## Aegis Focus v1.3.0

A calmer, smaller and more honest Aegis Focus.

**Design**
- New calm colour palette (slate teal, soft sage, muted lavender)
- Whole app is more compact: smaller buttons, cards and spacing
- No emojis anywhere in the app, icons only

**Home**
- Discipline score and level are now small chips
- Navbar shield upgrades Bronze, Silver, Gold, Platinum, Diamond with a progress ring
- Monk Shield card removed, calendar emoji replaced by an icon
- Discipline Snapshot shows only real focus time and screen time ("No data yet" otherwise)

**Productivity (replaces Stats)**
- Daily goals, reminders with real notifications
- Clean Streak: private daily check-in with a body and mind milestone timeline

**Settings**
- Block Shorts and Reels toggle now applies instantly
- System-wide AdBlocker plus new Block 18+ content option
- Emergency Exit Delay removed (Strict Mode has no emergency exit)
- Privacy card removed

**Fixes**
- Grant permission buttons are compact and the main button opens the next missing permission
- Removed demo screen-time numbers, sample app list and synthetic weekly history
