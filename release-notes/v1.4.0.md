## Aegis Focus v1.4.0

- One-time license keys: tap Get your key, message the owner on WhatsApp, Facebook or Instagram, then redeem the key to activate Pro. Each key works only once and is verified on the server.
- Admin panel can generate, list and revoke keys.
- New app logo and website favicon.
- Removed the old offline key check and the free-activation fallback.
- Calmer compact UI, Productivity tab with Clean Streak, system-wide ad blocker and 18+ DNS block (from v1.3.0).
