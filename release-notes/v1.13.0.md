## Aegis Focus v1.13.0

- Redesign: every main screen has a Cabin Sketch title with a hand-drawn underline, and section headings use the same style.
- Focus: sticky Start button, real app icons in the shielded apps and app lists, cleaner header.
- The Apps tab now lives inside Focus (Search & Manage All Apps), so the bottom bar has 5 tabs.
- Home: new "Today" card with habits done and which protections are on.
- Settings: cleaner heading, plus the Security card, Appearance and routine pickers from earlier releases.
