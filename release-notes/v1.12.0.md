## Aegis Focus v1.12.0

- Routines: choose which apps are blocked during a routine, and set the start and end time by typing it or using a clock (no more +/- buttons).
- Focus: the custom duration is now typed (90, 1h 30m, 1:30 or 1.5h) instead of using +/- buttons.
- App PIN lock now has a cleaner Security card with an ON/OFF badge and a bottom sheet for Set, Change and Remove.
- Routine length now shows as "17h" instead of "1020 min".
