## Aegis Focus v1.14.0

- Routines can now be edited and deleted: tap a routine card. A strict routine that is running right now cannot be changed, deleted or switched off until it ends.
- Home: Deep Work and Immersion (Strict Mode) now ask for confirmation first, and need the uninstall-protection permission like the Focus screen.
- Removed the wavy line under screen titles.
- YouTube Intent Mode: a title tester, a learning mode (notes what would be blocked, blocks nothing), an "Always allow this channel" button, and smarter matching (title and channel count more, word endings and small spelling mistakes are accepted).
