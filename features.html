ASR System Architecture

Engineered for Real Digital Discipline.

Every feature in ASR is crafted to build psychological friction against mindless habit loops while preserving deliberate deep focus.

Modular App & Web Blocker

Uses Android's low-latency AccessibilityService combined with fallback UsageStatsManager monitoring. When a blocked distracting app is opened, ASR intervenes immediately and pushes the app to background before dopamine loops can form.

  • ✓ Sub-50ms instant detection
  • ✓ Pro: Domain-level website blocking in browsers
  • ✓ System whitelist protects dialer, emergency & launcher

Tamper-Resistant Strict Mode

When Strict Mode is active, session parameters, timer duration, and blocked app lists become strictly immutable in both UI and domain layers. Normal cancellation is disabled.

  • ✓ Free Tier: Genuine strict sessions up to 3 hours
  • ✓ Pro Tier: Unlimited strict sessions (6h, 12h, custom)
  • ✓ "Ready to commit?" review dialog before locking in

Mindful Pause & Reason Selection

Instead of harsh unhelpful lockouts, ASR presents a 5-second breathing moment and asks for your intention (Important / Just checking / Bored / Habit).

  • ✓ 5-second calm breathing countdown
  • ✓ Pro: Escalating delay on repeated attempts (5s → 10s → 20s → 30s)
  • ✓ Logs reasons into private local analytics

Transparent Discipline Score

A documented, mathematical behavioral score from 10 to 100 based on your completed sessions, consistency, streaks, and distraction avoidance.

Score = Base(80) + StreakBonus(0–5) + GoalBonus(0–5) − DistractionPenalty(0–20) − ExitPenalty(0–20)

Emergency Exit with Multi-Friction

If an actual emergency happens during Strict Mode, users can exit by navigating through a calm cooldown timer and manually typing the mindful confirmation phrase.

  • ✓ Configurable cooldown delay (5s, 10s, 15s)
  • ✓ Phrase typing: "I choose to break focus"
  • ✓ Audited locally in `emergency_exits` table

Epoch-Based Crash Survival

Timers are never kept solely in volatile memory. ASR records exact epoch millisecond timestamps into local Room SQLite. If the device reboots or app is killed, the session seamlessly restores.

  • ✓ Survives system kills & restarts
  • ✓ 100% on-device SQLite database
  • ✓ Zero server sync, zero accounts required
