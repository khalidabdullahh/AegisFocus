## 🌟 Key Features & Philosophy

- **100% Offline & Private (Zero Tracking)**:
  - No mandatory account creation or cloud database tracking.
  - All focus logs, app block rules, and discipline scores live strictly inside your device's local Room database (`aegis_focus.db`).
- **One-Time Server-Verified License Keys**:
  - Pro keys purchased via direct contact (WhatsApp / Instagram / Facebook) and redeemed securely via Supabase RPCs. Each key works exactly once.
- **Calm, Compact UI & Tier Shield**:
  - Calmer palette (slate teal, soft sage), compact layout without emojis, and dynamic navbar shield that upgrades across Bronze, Silver, Gold, Platinum, and Diamond.
- **Productivity & Clean Streak Tab**:
  - Daily goals, customizable routine reminders with real notifications, and private Clean Streak check-ins with body and mind milestone timelines.
- **System-Wide AdBlocker & 18+ Content DNS Blocker**:
  - On-device local DNS filtering powered by AdGuard DNS, blocking ads, malicious trackers, and adult content without battery drain.
- **Unbreakable Strict Mode & Anti-Uninstall**:
  - Android Device Administrator lock preventing impulsive app uninstallation or disabling during active focus sessions.
- **Mindful Pause & Adaptive Friction**:
  - Escalating cooldown timers (5s → 10s → 20s → 30s) and intentional mindful prompts before app unblocking.
- **In-App Admin License Key Manager**:
  - Access the admin panel (3 taps on Aegis Focus in Settings) to generate, list, and revoke keys (requires `super_admin` credentials).

## ⚠️ Google Play Protect Notice (Sideloaded APKs)

When downloading and installing the APK directly without the Google Play Store, Android Play Protect may show a warning:
> *"Unsafe app blocked"* or *"Play Protect doesn't recognise this app's developer"*

### 💡 How to Install (Takes 2 Seconds):
1. On the Play Protect dialog, tap **"More details"** (or **"অতিরিক্ত তথ্য"**).
2. Tap **"Install anyway"** (or **"যেকোনোভাবে ইনস্টল করুন"**).

### 🔍 Why Does This Happen?
1. **Sideloading**: Any APK installed outside Google Play triggers a standard developer verification prompt.
2. **Sensitive Focus Permissions**: Aegis Focus uses Android's native `AccessibilityService` (to block apps in real-time) and `DeviceAdminReceiver` (to prevent cheating or uninstalling during Strict Mode). Google flags these high-level permissions on new unindexed apps until published on the Google Play Store.

## 🔑 License Keys (one-time, server-side)

Keys are created, stored and redeemed on the server (Supabase). Each key works exactly once and
the app never contains anything that can create or validate a key.

**Create a key (admin only)**
1. Sign in to the app with the admin account.
2. Open **Settings (⚙️)** and tap **`Aegis Focus • v…`** 5 times quickly.
3. Pick a plan, add an optional buyer note and tap **Generate Key**.

The panel only appears for the admin email, and the server checks `profiles.role` again on every
call. To make an account an admin, run this once in the Supabase SQL Editor (the app cannot do it):

```sql
update public.profiles set role = 'super_admin'
where id = (select id from auth.users where email = 'YOUR_EMAIL_HERE');
```

Database setup order: `supabase_schema.sql`, then everything in `supabase/migrations/` by date.
