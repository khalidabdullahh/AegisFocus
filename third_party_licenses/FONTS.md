# Fonts

The app fonts are bundled under the SIL Open Font License 1.1 (see the OFL files in this folder).

- Cabin Sketch (Impallari Type): titles and big numbers.
- Josefin Sans (Santiago Orozco): all other text.
- Hind Siliguri (Indian Type Foundry): Bangla letters. It is merged into the two fonts above
  (res/font/aegis_*.ttf), so Bangla text uses it automatically wherever the Latin font is used.
