# 🤝 Contributing to AegisFocus (ASAR)

Thank you for your interest in contributing to **AegisFocus**!

AegisFocus is a native Android focus and digital discipline engine developed and exclusively owned by **Khalid Abdullah**. While the project is source-available and protected against commercial cloning, community contributions such as bug fixes, accessibility improvements, localization, and documentation are welcome.

---

## 🛠️ Contribution Workflow

1. **Open an Issue:** Discuss significant bug fixes or feature proposals before writing code.
2. **Fork the Repo:** Create a fork and a new branch:
   ```bash
   git checkout -b feature/improvement-name
   ```
3. **Commit & Test:** Write clean, modular Kotlin/Compose code and test on Android emulator or physical device.
4. **Submit a Pull Request (PR):** Describe the issue resolved and attach screenshots if applicable.
